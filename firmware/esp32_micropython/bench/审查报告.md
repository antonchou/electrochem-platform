# bench/ 台架脚本与 main.py 审查报告

- 日期：2026-10-10
- 审查对象：
  - `bench/` 下 5 个脚本：树莓派上的旧版代码，10-10 原样入库，没有任何改动。
  - `main.py`：按下面的硬件前提检查能不能上板。
  - 提交 85378e5 里的文档断言。
- 硬件前提（用户 10-10 确认）：
  - 主控是 ESP32-S3。
  - 引脚：ADS1256 SCLK/DIN/DOUT/CS/DRDY = 18/6/19/5/16；MCP4728 SDA/SCL = 8/9；DS18B20 DQ = 4。
  - 回路：MCP4728 A 通道 → 电极 1 → 溶液 → 电极 2 → 10 kΩ 采样电阻 → **GND**。
  - 读数：U = AIN0−AIN1，I = (AIN2−AIN3)/R。
- 依据分三类，每条发现都注明属于哪一类：
  - (a) 数据手册：ADS1256 用 TI SBAS288K（2013-09 版），页码按该 PDF 标注。
  - (b) 源码或官方文档。
  - (c) 需台架实测，第五节给出了具体步骤。
- 本报告没有任何一条结论来自实物运行结果。脚本在板上实际怎么跑、输出什么，都还没有核实。

## 一、结论摘要

1. `electrochem.py` 和 `electrode_measure.py` 读出的"电导率"不是溶液电导率。
   - 原因：它们用两电极直流激励，项目路线文档明令禁止这种做法。
   - ADS1256 的读数流程本身已按数据手册核对，没有问题。
2. `main.py` 在当前接线（采样电阻下端接 GND）下**不能上板**。
   - 它的"静息 0 V"实际是电池加采样电阻对地 1.024 V 直流，`probe()` 一运行就加上。
   - 方波只在 0.824~1.224 V 之间变化，电流从不反向。
   - 要么改线，要么改设计（第四节 D1）。
3. `ads1256_probe.py` 会把负电压显示成约 +10 V：板上 MicroPython 不支持 `signed` 参数。另外它写 ADCON 0x08，实际上打开了 0.5 µA 传感器检测电流，注释写错了。
4. `mcp4728_test.py` 停止后 A 通道一直保持 0.825 V。这时如果电极在溶液里，就会长时间加着直流。
5. `temptest.py` 第一个读数是 85 °C 上电默认值，之后每个读数都是上一轮的，滞后约 1 s。
6. GPIO19 是 S3 原生 USB 的 D−。如果树莓派接的是板子的原生 USB 口，SPI 一初始化就可能断开连接，要先确认接的是哪个口（D2）。
7. 采样电阻用 10 kΩ 时，`main.py` 会把 ≳14.9 mS/cm 的溶液误判为 SHORT_CIRCUIT，12.88 mS/cm 标准液正好落在边缘（D3）。
8. 有一条怀疑被数据手册证伪：换通道后**不会**读到上一个通道的旧数据（见 V1）。

## 二、发现清单（按严重度）

### F1 致命：直流两电极测得的不是溶液电导率

- 位置：`electrochem.py:7`（`DAC_CODE`）、`:218`（κ = G·K），以及 `electrode_measure.py` 同样的流程。
- 问题：电极上一直加着 0.5 V 单向直流，程序把 I/U × K 当成电导率输出。
- 依据：
  - 项目文档 `docs/电导率I-V测量链路与开发路线.md` 第 41 行写明：禁止用未验证的直流长期激励代替交流测量，以免电极极化、电解和气泡改变结果。
  - 物理估算：双电层相当于串在溶液电阻上的电容。
    - 按光面电极约 1 cm²、双电层 10~50 µF/cm² 估算，两界面串联约 5~25 µF。
    - 回路电阻约 11 kΩ（10 kΩ 采样电阻加约 1 kΩ 溶液电阻），时间常数 τ ≈ 55~280 ms。
    - 几秒之后，电流主要来自法拉第漏电（溶解氧还原、电极材料反应），不再由溶液电阻决定。
    - 电极材料和面积未知，这只是量级估算，属于 (c) 需实测。
- 影响：
  - 读数在最初几秒内迅速下降，然后缓慢漂移，数值会远低于真实电导率。
  - `sample_pair` 的"变化较快"过滤（5%）挡得住开头的快速衰减，挡不住后面的缓慢漂移。所以过滤通过的读数看起来稳定，但数值是错的。
  - 用 1 kΩ 电阻代替电解池时，不会出现这些现象。
- 建议：
  - 这个脚本只用于电阻负载上的链路检查，输出里不要再出现"电导率"。
  - 溶液测量改走双极性方波（`main.py`），前提是先解决 F2。
  - 判定方法见第五节第 4 步。

### F2 致命：main.py 在采样电阻接 GND 时"静息"并不是 0 V

- 位置：`main.py:423`（`buf_rest`：VA=VB=1.024 V）、`:462` `safe()`、`:666` 与 `:719` 的日志"电池两端已回 0 V"、`:701` `dc()`。
- 问题：
  - 固件的前提是采样电阻下端接 VB（1.024 V 虚拟地），见 README 第 1 节。
  - 现在下端接 GND，于是：
    - 静息、出错和 Ctrl-C 之后，电池加采样电阻对地都是 1.024 V 直流。`probe()` 第一步就写这个值（`:397` → `_init_dac`）。
    - 方波期间 VA 在 0.824 和 1.224 V 之间变化，电流方向始终不变，正负半周的 U 同号。
    - `dc(v)` 实际加上的是约 1.024+v V，不是 v。
- 依据：(a) 本仓库代码与 README 第 1 节的接线前提；数值按 `DAC_VREF_V = 2.048`、中点码 2048、幅值码 400 算出。
- 影响：
  - 电极长期承受接近 1 V 的单向直流，与 F1 同类，而且更接近水的分解电压 1.23 V。
  - 每帧都会带 WAVEFORM_UNSTABLE（正负半周不对称度约等于 1）。
  - 日志里"已回 0 V"的说法是错的。
- 建议：先做 D1 的决定。在那之前，别在接着溶液的电极上运行 `main.py` 的任何函数（包括 `probe()`）。

### F3 严重：ads1256_probe.py 读负电压会显示成约 +10 V

- 位置：`ads1256_probe.py:64` `int.from_bytes(spi.read(3), 'msb', True)`。
- 问题：
  - MicroPython 的 `int.from_bytes` 不处理 `signed`，结果总按无符号解。
  - 字节序参数只认 `'little'`，其他任何值都当大端，所以 `'msb'` 是碰巧能用。在 CPython 里这一行会直接报 ValueError。
- 依据：(b) micropython/micropython `py/objint.c` 的 `int_from_bytes`，源码注释原文："TODO: Support signed param (assumes signed=False at the moment)"（2026-10 的 master；更早的版本同样如此）。
- 影响：
  - 第三步零点检查（AIN0 接 GND）只要有一点负偏置，比如 −1 mV，就会打印约 9.999 V。
  - 输入稍偏负时，零点检查会被误判成"读数异常"；输入稍偏正时又看不出问题。
- 建议：改成手动补码，和 `electrochem.py:141` 起的写法一样：`raw = (b0<<16)|(b1<<8)|b2; if raw & 0x800000: raw -= 1<<24`。

### F4 严重：mcp4728_test.py 停止后 DAC 不清零

- 位置：`mcp4728_test.py:16`（A 通道码值 1024）、`:90-91`。
- 问题：Ctrl-C 只停止打印。A 通道保持 3.3×1024/4096 = 0.825 V，软重启也不会清零（DAC 是独立的 I2C 器件）。
- 依据：(a) 脚本自己在 `:68` 和 `:91` 也提示了"DAC outputs remain set"。
- 影响：如果电极这时接在溶液里，0.825 V 单向直流会一直加着，直到下一个程序把 DAC 写回 0 或断电。效果和 F1 一样，而且时间更长，事后很难发现。
- 建议：退出时把四个通道写回 0。或者在 README 和脚本开头写明只能在电阻负载上运行。

### F5 严重（待确认）：DOUT 接的 GPIO19 是 S3 原生 USB 的 D−

- 位置：`ads1256_probe.py:6`、`electrochem.py`/`electrode_measure.py` 的 SPI 初始化（`miso=Pin(19)`）、`main.py:40`。
- 问题：S3 的 GPIO19/20 默认用作 USB-Serial/JTAG，重新配置成普通 GPIO 后，这一路 USB 功能会被关闭。
- 依据：(b) ESP-IDF ESP32-S3 GPIO 文档："GPIO19 and GPIO20 are used by USB-JTAG by default"；改作普通 GPIO 后 USB-JTAG 会被禁用。
- 影响：
  - 树莓派接原生 USB 口时，脚本一建 SPI，Thonny 或 v2 的串口就会断开。
  - 接 USB 转串口芯片那个口则不受影响。如果现在能正常看到输出，说明接的大概率是后者，但没有核实。
  - 组员换一个口就会遇到"一运行就断线"的问题，很难查。
- 建议：按第五节第 0 步确认接口。要彻底消除风险，就把 DOUT 改接一个空闲的普通 GPIO，比如 GPIO13，同时改 `main.py` 的 `ADS_MISO` 和 bench 脚本。S3 的 strapping 引脚是 0/3/45/46，flash/PSRAM 占用 26~37，GPIO13 都不在其中。

### F6 一般：10 kΩ 采样电阻会让 main.py 把高电导溶液误判为短路

- 位置：`main.py:50`（`R_SHUNT_OHM`）、`:76`（`SHORT_U_RATIO` = 1%，即 U < 2.0 mV）。
- 依据：按 K=1.5 cm⁻¹、幅值 0.2 V 计算（纯欧姆，未计极化）：

  | 溶液 | 溶液电阻 | U 幅值 | I 幅值 | 采样电阻压降 |
  |---|---|---|---|---|
  | 84 µS/cm | 17.9 kΩ | 128 mV | 7.2 µA | 72 mV |
  | 1413 µS/cm | 1.06 kΩ | 19.2 mV | 18.1 µA | 181 mV |
  | 12.88 mS/cm | 116 Ω | 2.30 mV | 19.8 µA | 198 mV |

  U = 2.0 mV 对应约 14.9 mS/cm。

- 影响：
  - 用 12.88 mS/cm 标准液标定时，读数离阈值只有 15%，噪声或极化就可能触发 SHORT_CIRCUIT，v2 会判 FAIL。
  - 再高的电导就完全测不了。
- 建议：按样品量程选采样电阻，使它和溶液电阻同一量级（1413 量级配 1 kΩ），见 D3。

### F7 一般：temptest.py 首个读数是 85 °C，之后每次滞后一拍

- 位置：`temptest.py:10-11`。转换要 750 ms，脚本只等 100 ms 就读。
- 依据：(a) DS18B20 数据手册：12 位转换最长 750 ms，温度寄存器上电值为 +85 °C；转换完成前读到的是上一次转换的结果（页码未逐页核对）。
- 影响：
  - 冷启动后的第一个读数是 85.00 °C。
  - 之后每个读数都是上一轮循环的转换结果，约滞后 1.1 s。
  - 读取时如果 CRC 出错，驱动会抛异常（见 V6），脚本没有捕获，循环就此终止。
- 建议：等 ≥750 ms 再读，或者先读后发下一次转换；加 try/except。`main.py` 的 `TempProbe` 已经处理了这些情况，可以照搬。

### F8 一般：ads1256_probe.py 写 ADCON 0x08 打开了传感器检测电流

- 位置：`ads1256_probe.py:53`，注释写的是"时钟输出关, gain=1"。
- 依据：(a) SBAS288K p.30 Table 23 与 ADCON 位定义：bit6-5 为 CLK，bit4-3 为 SDCS，bit2-0 为 PGA。0x08 即 SDCS=01，开启 0.5 µA 传感器检测电流（p.3 电气特性、p.15 Sensor Detect）。打开 SDCS 时输入缓冲会被强制打开。
- 影响：
  - 第三步读 AIN0 时，被测源上叠加了 0.5 µA。源阻抗高或悬空时读数被抬高，所以"悬空约 17 mV"这类读数不能用来判断零点。
  - 作为寄存器写读测试，这一步仍然有效。
- 建议：写读测试换成 0x00 或 0x20，注释更正。

### F9 一般：electrochem.py 不测温度，K 值来源不明，却输出"电导率"

- 位置：`electrochem.py:13`（`CELL_K_CM = 1.5`）、`:221`。
- 依据：路线文档第 9、14、24 行：κ(T) = Kcell·G，Kcell 由标准液标定，再按经验证的模型折算到 κ25；而且温度必须和 U/I 一起记录。
- 影响：
  - K=1.5 若是标称值，误差直接进入 κ。
  - 没有温度，就无法和标准液比对，也算不出 κ25。
  - 这条比 F1 次要，因为 F1 已经否定了这个读数本身。
- 建议：问清 K=1.5 的来源（D5）。今后的电导率一律由 v2 计算，设备端只输出 U/I/T。

### F10 一般：U、I 交替采样时间重心错开，每次读数要多等一个转换周期

- 位置：`electrochem.py:155-158`（顺序 U1→I1→U2→I2）、`:125`（`write_register` 会先等一次 DRDY）。
- 依据：
  - 读完 RDATA 后 DRDY 变高（p.34 RDATA 说明）。
  - `write_register` 要等下一个 50 SPS 转换完成（≤20 ms），SYNC 之后再等 20.18 ms 建立时间。所以每次读数约 40 ms，U 和 I 的时间重心相差约 40 ms。
  - 数据手册 p.21 的推荐做法是 DRDY 一变低就改 MUX，这样每次读数约 20 ms。
- 影响：电流在衰减时（F1 的情形），这个时间差会让 G 产生系统偏差。和 F1 相比是次要问题。
- 建议：如果保留这个脚本，按 U I I U 的顺序交错采样，和 `main.py` 一样。

### F11 建议

- **AIN3 正好在缓冲输入范围的下限上。**
  - `electrochem.py:106` 打开了输入缓冲，AIN3 接 GND，就是 0 V。
  - 缓冲打开时，输入的绝对电压范围是 AGND 到 AVDD−2.0 V（p.3），0 V 正好是下限，不算超出规格。但模块地与 ESP32 地之间的任何偏差都会让它越界。
  - 按 D1 改接 VB 后，这个问题自然消失。
- **`electrode_measure.py` 已被 `electrochem.py` 取代。** 它在模块顶层就初始化了 SPI 和 I2C，`R_SHUNT=None`。建议标为废弃。
- **`electrochem.py:288` 吞掉了异常堆栈**，排障时只能看到一行消息。

## 四、待用户决策

- **D1 采样电阻下端接哪里。**
  - 方案 A（推荐）：改接 MCP4728 B 通道（VB）。
    - 只动一根线，`main.py` 不用改，双极性方波净直流为 0。
    - bench 脚本把 B 写成 0 V，相当于仍然接地，所以照样能用。
    - 代价：电路对地有 1.024 V 共模电平，溶液里的金属件不能和 GND 导通（README 第 1 节）。
  - 方案 B：保持接 GND，改固件。
    - 单个 DAC 输出不了负电压，只能做 0/+V 的单极性方波，净直流等于幅值的一半，极化仍然会累积。
    - 不推荐。
- **D2 DOUT 是否改离 GPIO19。** 取决于树莓派接的是哪个 USB 口（第五节第 0 步）。
- **D3 采样电阻取多大。** 按目标样品量程选（见 F6）；或者保留 10 kΩ、调低 `SHORT_U_RATIO`，但那样高电导时 U 的信噪比会变差。
- **D4 bench/electrochem.py 怎么定位。** 降级为"电阻负载链路检查工具"（去掉"电导率"输出），或者直接退役。
- **D5 K=1.5 cm⁻¹ 从哪来。** 是电极标称值还是标定值？电极材料和面积是多少？F1 的定量估算需要这些数据。

## 五、台架验证清单（按顺序执行；只用树莓派 + Thonny + 现有器件 + 万用表 + 一个 1 kΩ 电阻 + 一节 1.5 V 干电池）

0. **记录环境。**
   - Thonny Shell 里执行 `import sys; print(sys.implementation)`、`import os; print(os.uname())`。
   - 树莓派上执行 `ls -l /dev/serial/by-id/`：名字含 `Espressif` 的是原生 USB 口，含 `1a86`/`CH34x`/`CP210x` 的是串口芯片口（对应 F5、D2）。
1. **DS18B20。** 冷上电后运行 `temptest.py`：第一行预期是 85.00；用手捏住探头，读数应在下一行之后才开始上升（证实 F7）。
2. **ADS1256 零点。**
   - AIN0 短接 GND，运行 `ads1256_probe.py`：读数要么约 0 V，要么约 9.99 V（后者即 F3）。
   - 再把 AIN0 接 GND、AINCOM 接一节 1.5 V 干电池正极（负极接 GND），真实值为 −1.5 V：如果打印约 8.5 V，即证实 F3。
3. **电阻负载跑 `electrochem.py`（同时复核 V1）。**
   - 用 1 kΩ 电阻代替电解池，不接电极。
   - 预期 U ≈ 45.5 mV、采样电阻压降 ≈ 455 mV、I ≈ 45.5 µA、表观电阻 ≈ 1000 Ω，5 分钟内不漂移。这一步验证 ADC 链路和换算。
   - 如果 U 和 I 被读串了（V1 被推翻），会看到 U ≈ 455 mV、表观电阻 ≈ 100 kΩ。
4. **判定 F1。**
   - 电极浸在 1413 µS/cm 标准液（没有标准液就用自来水）中，运行 `electrochem.py` 5 分钟，每组读数都记下来。
   - 理论预期：开头几秒内表观电导率快速下降，之后缓慢漂移，数值远低于标称值。
   - 和第 3 步对比。测完立即 Ctrl-C，确认打印出"DAC A已设置为0V"。
5. **按 D1 改线后。**
   - 用电阻负载运行 `import main; main.probe()`。
   - 万用表量电极 1（VA）到采样电阻下端（VB）的电压，应约为 0 V；`main.volts(2, 3)` 应约为 0。
6. **`main.run(10)`。**
   - 1 kΩ 负载、10 kΩ 采样电阻：预期 `voltage_raw_v` ≈ 18.2 mV，`current_raw_a` ≈ 18.2 µA，G ≈ 1.000e-3 S。
   - 除温度相关的标志外，不应有其他质量标志。
   - 设 `DIAG = True` 时，u_pos ≈ −u_neg。
7. **溶液上的极化检查。** 再按 README 第 7 节做（换频率和 `SETTLE_FRACTION`，看 G 变不变）。
