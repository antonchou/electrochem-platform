# 电导率 I–V 测量链路与开发路线

> 状态：当前硬件路线的权威说明
> 生效日期：2026-08-22
> 取代：BA121S/CM2 等现成电导率模块直接输出 EC 的旧路线，以及旧版《架构图》《全流程开发路线图》中与该路线冲突的内容。

## 1. 路线结论

溶液电导率不由现成电导率模块直接给出。系统对导电池电极施加受控交流或双极性激励，同步采集电极两端电压与回路电流，并保存温度。软件先由电压、电流计算电导，再通过标准液标定得到的电池常数计算测量温度下的电导率，最后按经验证的温度模型折算到 25 °C。

```text
受控激励 → 导电池电极 → 电压通道 U + 电流通道 I → ADC/采集控制
                                                ↓
温度 T → 通道校准 → G(T)=I/U → κ(T)=Kcell·G(T) → 温度补偿 → κ25
```

本链路是电导率测量链路，不等同于三电极恒电位仪。WE/RE/CE 与伏安法等功能仍属于后续电化学扩展，不得混入本阶段。

## 2. 计算与可追溯性

在激励频率、波形和取样算法已通过台架验证的前提下：

- 电导：`G(T) = I / U`。实现可采用同频幅值、RMS 或复导纳方法，必须在硬件设计冻结时明确，不能混用。
- 电导率：`κ(T) = Kcell × G(T)`，其中 `Kcell` 由可追溯标准液标定，单位与计算链必须一致。
- 线性温度补偿仅在适用范围验证后使用：`κ25 = κ(T) / [1 + α × (T - 25)]`。
- 若样品不满足线性模型，应采用标准液查表或溶液专用模型，并记录模型版本、参数和适用温区。

`U/I/T` 是不可变原始量；`G(T)`、`κ(T)`、`κ25` 是可重算结果。校准、滤波、温补和人工修订不得覆盖原始数据。

## 3. 硬件边界

正式方案至少包括：

- 导电池及电极。二电极或四电极拓扑由量程、极化和接触阻抗台架结果决定，当前不预先冻结。
- 交流或双极性激励源。激励幅值、频率、占空比和量程切换必须可配置、可记录。
- 电压测量通道，以及基于采样电阻或跨阻放大器的电流测量通道。
- ADC、输入保护、抗混叠滤波、基准与供电隔离；ADS1256 可作为候选 ADC，但必须通过噪声、带宽和同步采样验证。
- 温度传感器及其机械位置。温度必须代表导电池附近溶液，而非机箱或板卡温度。
- ESP32-S3 或树莓派侧的时序控制、采集、质量检查与数据传输。

禁止用未验证的直流长期激励代替交流测量，以免电极极化、电解和气泡改变结果。激励频率、幅值、电流量程、采样率、二/四电极拓扑均为台架选型项，不以器件宣传参数直接冻结。

## 4. 数据分层与目标协议

目标原始帧至少保留：

| 分层 | 字段示例 | 说明 |
|---|---|---|
| Raw | `voltage_raw_v`, `current_raw_a`, `temperature_raw_c` | ADC/通道换算后的原始物理量，不可变 |
| Calibrated | `voltage_cal_v`, `current_cal_a`, `conductance_s`, `kappa_t_us_cm` | 应用通道校准与电池常数 |
| Derived | `kappa_25_us_cm`, `representative_value`, `fit_result` | 温补、判稳、统计和拟合结果 |
| Trace | `seq_no`, `timestamp_utc`, `monotonic_ms`, `sensor_path_id`, `calibration_id` | 时序与溯源 |
| Configuration | `excitation_frequency_hz`, `excitation_amplitude_v`, `range_id`, `compensation_model`, `alpha_per_c` | 必须随实验版本化 |
| Quality | `quality_flags` | 饱和、欠量程、开路、短路、温度无效、未校准、校准过期、波形不稳等 |

当前 Mock/API 在线通道已经完成 V2 切换：只接受显式 `message_type=measurement`、`schema_version=2.0` 的完整分层帧，默认链路为 `EC_IV_CELL_MOCK`。V1 `ec` 只保留在数据库 `legacy_ec_us_cm` 历史读取层，不得进入实时 WebSocket、浏览器模拟源或在线验收。

## 5. 校准与验收

校准记录至少包含：标准液标称值、批次与有效期、温度、导电池 ID、电极状态、激励设置、电压/电流通道增益与零点、电流采样电阻或 TIA 参数、`Kcell`、温补模型及版本、操作者和时间。

台架验收顺序：

1. 用精密电阻/阻抗负载验证电压通道、电流通道、相位/波形算法、量程切换、开短路与饱和保护。
2. 用标准液标定 `Kcell`，至少覆盖目标量程的低、中、高点，并保留重复测量。
3. 在多个温度点验证 `κ(T)` 与 `κ25`，确认补偿模型和适用温区。
4. 验证电极重复装夹、浸没深度、气泡、搅拌、污染和极化影响。
5. 完成 30 分钟以上连续采集，验证 `U/I/T → G → κ(T) → κ25 → WebSocket → SQLite → Web` 全链路。

在上述证据完成前，不声明精度、量程、温补误差或跨样品通用性。

## 6. 修订后的阶段路线

| 阶段 | 目标 | 关键产出 |
|---|---|---|
| Phase 0–3、7 | 已完成软件骨架、Mock、Web、SQLite、历史与导出 | 保持现状；Mock 改为模拟 I/V 推导值时须兼容现有测试 |
| Phase 4 | 温度通道接入 | DS18B20 驱动、位置验证、温度校准与质量标志 |
| Phase 5A | 电气测量台架 | 激励源、电压/电流 AFE、ADC、精密负载测试、保护与量程 |
| Phase 5B | 导电池与标准液校准 | 电极方案、`Kcell`、重复性、低中高点、校准记录 |
| Phase 5C | 计算与温补闭环 | `G/κ(T)/κ25`、模型版本、质量标志、Raw/Calibrated/Derived 落库 |
| Phase 6 | pH/ORP 等其他传感通道 | 与电导率链路分离开发 |
| Phase 8 | 判稳、QC、拟合与报告 | 代表值、误差预算、残差与报告 |
| Phase 9 | ESP32-S3 实时控制 | 激励时序、同步采集、协议、硬件在环测试 |
| Phase 10+ | 三电极电化学扩展 | 恒电位仪、CV/CA 等；不得倒灌进电导率 MVP |

## 7. 变更影响

- BA121S/CM2 及“模块直接输出电导率”退出正式采购、校准、驱动和验收路线。
- 原有 `ec_raw` 在目标模型中不再代表硬件原始量；正式数据必须先保存 `U/I/T`。
- ADS1256、激励 DAC、采样电阻/TIA 和模拟前端从“三电极后续器件”调整为电导率 I–V 链路候选器件。
- 旧图和旧版 Word 文档只作为历史记录；当前实现与后续设计以本文件、升版需求规格和升版交接文档为准。
