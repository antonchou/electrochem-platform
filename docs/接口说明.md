# 接口说明（交付物 #4）

## 1. WebSocket 实时数据流

- **地址**：`ws://<host>:8000/ws/stream`
- **协议**：UTF-8 JSON
- **速率**：实验运行期间 ≥1Hz（模拟源为 10Hz）

### 数据帧

```json
{
  "timestamp": 12.35,
  "ec": 1412.8,
  "temperature": 25.3,
  "status": "running",
  "schema_version": 2,
  "device_id": "MOCK-IV-01",
  "firmware_version": "0.1.0",
  "range_id": "WIDE",
  "voltage_raw_v": 1.0,
  "current_raw_a": 0.001413,
  "temperature_raw_c": 25.3,
  "conductance_s": 0.001413,
  "kappa_t_us_cm": 1412.8,
  "kappa_25_us_cm": 1412.8,
  "quality_flags": "SIMULATED"
}
```

旧前端仍可读 `timestamp` / `ec` / `temperature` / `status`。`ec` 是 κ25 的兼容别名；计算链拒绝（电压 ≤ 0 等）时 `ec` 与 κ25 为 `null`，原始 U/I/T 仍下发。

| 字段 | 类型 | 单位 | 含义 |
|---|---|---|---|
| `timestamp` | number | s | 实验开始后的时间（float） |
| `ec` | number \| null | μS/cm | 实时电导率（兼容层 = κ25；非法计算时为 null） |
| `temperature` | number | °C | 电极温度 |
| `status` | string | — | `idle`/`running`/`stopped`/`error` |

### 状态广播帧

某些时刻（开始/停止/重置）服务端会推送只含 `status` 的帧：

```json
{ "status": "stopped" }
```

前端处理规则：`ec`/`temperature` 缺失的帧只更新实验状态，不追加数据点。

### 异常处理约定

- 非法 JSON、缺 `timestamp`/`temperature`、非数字 `ec`、`NaN`、未知 `status` → 前端**丢弃该帧并提示**，页面不崩溃。`ec: null` 是合法帧（计算链拒绝）。
- 断线 → 3 秒内提示「已断开/重连中」，并自动重连（指数退避 ≤5s）。
- 连接存活但 3 秒无数据 → 提示「数据流超时」。

## 2. REST 控制接口

基础地址：`http://<host>:8000`

| 方法 | 路径 | 请求体 | 响应 |
|---|---|---|---|
| POST | `/api/experiment/start` | `{sample_id?, sensor_path_id?, title?, operator?, objective?, concentration_mmol_l?}` | `{ok, status, experiment_id?, sample_id?}` |
| POST | `/api/experiment/stop` | — | `{ok: true, status: "stopped", experiment_id}` |
| POST | `/api/experiment/reset` | — | `{ok: true, status: "idle"}` |
| GET | `/health` | — | `{status: "ok", experiment: "idle"}` |
| GET | `/api/experiment/current` | — | `{status, experiment_id, sample_id, experiment_uid}` |

> `start` 请求体为**可选**（Phase 7 样品溯源）。不传时默认样品 `SAMPLE`、链路 `MOCK_EC_IV`。`concentration_mmol_l` 须 ≥0，写入 `samples`；停止后结果区从实验详情读取 QC 与浓度。旧标识 `CM2_WIDE` 仍可显式传入；不代表正式硬件采用 CM2。目标真实链路 ID 应改为 `EC_IV_CELL_<编号>`。

响应统一为：

```json
{ "ok": true, "status": "running", "message": null, "experiment_id": 12, "sample_id": "NACL_004" }
```

- `ok=false` 表示操作无效（如运行中重复 start），`message` 为原因。
- 停止后再次 `start` 且样品编号不变：续跑同一实验（`resumed: true`），不新建记录。换样品或先 `reset` 再 `start` 才会开新实验。「重新开始」= `reset` + `start`。
- 错误码：`4xx`（客户端错误）/ `5xx`（服务端错误）；前端应捕获异常并给出可理解提示。

## 2.5 历史查询与导出（Phase 7）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/experiments` | 历史实验列表（含每实验 `frame_count`） |
| GET | `/api/experiments/{id}` | 实验详情：元信息 + `samples[]` 样品汇总 |
| GET | `/api/experiments/{id}/frames?limit=&offset=` | 原始帧分页（字段见下） |
| GET | `/api/experiments/{id}/export.csv` | 导出原始帧 CSV（Excel 可打开，`Content-Disposition: attachment`） |
| GET | `/api/experiments/{id}/export.json` | 导出完整实验 JSON（`Content-Disposition: attachment`） |

帧字段：`seq_no, timestamp_utc, monotonic_ms, t_seconds, sensor_path_id, sample_id, ec_raw, temperature_raw, k25, quality_flags, status`。

v5 起原始帧落库并导出：`voltage_raw_v, current_raw_a, conductance_s, kappa_t_us_cm, kappa_25_us_cm, schema_version, device_id, firmware_version, range_id, calibration_id, excitation_frequency_hz, excitation_amplitude_v, compensation_model`。其中 U/I/T 属 Raw，G/κ(T) 属 Calibrated，κ25 属 Derived（规范名 `kappa_25_us_cm`）。开始实验会写入 `calibration_records`（当前为 mock 电池常数记录）。详细定义见 `docs/电导率I-V测量链路与开发路线.md`。

数据约束（REQ-D-001）：`raw_frames` 为 **append-only**，服务端触发器禁止 `UPDATE`/`DELETE`，原始数据不可篡改；导出即取证。

## 2.6 备选公式拟合

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/analysis/fit` | 对数据点做化学备选公式拟合，按 R² 排序返回参数与拟合曲线 |

请求体：

```json
{
  "x": [0.0, 0.1, 0.2],
  "y": [1413.1, 1413.0, 1412.9],
  "models": ["linear", "quadratic"],
  "x_axis": "time"
}
```

- `x`/`y` 等长且 ≥3 个点；`models` 缺省为该轴全部模型。
- **`x_axis`** 标明 X 轴物理含义，决定化学模型池：
  - `time`（默认，EC-时间）：`linear`、`quadratic`、`first_order`（一阶指数饱和 y=a−b·e^(−k·x)）、`exponential`（y=a·e^(b·x)，要求 y>0）、`logarithmic`（y=a+b·ln(x)，要求 x>0）、`power`（y=a·x^b，要求 x>0,y>0）
  - `temperature`（EC-温度 °C）：`linear`（线性温补）、`quadratic`、`arrhenius`（Arrhenius y=a·e^(−Ea/(R·T))，T=x+273.15，输出 `Ea_kJ_mol`，要求 y>0）
  - `concentration`（EC-浓度）：`linear`（线性标定）、`quadratic`、`kohlrausch`（Kohlrausch y=a+b·c−K·c^1.5，a=κblank、b=Λ0、K，要求 c>0；无真实浓度字段时前端禁用拟合）
  - 跨轴模型会被忽略（如 temperature 轴下请求 `kohlrausch`）。
- 响应：`{ best, models: [{model, label, params, r2, rmse, n, fitted}] }`，`fitted` 为 150 个采样点的拟合曲线。

## 3. 调试接口（仅模拟源，验收用）

| 方法 | 路径 | 用途 |
|---|---|---|
| POST | `/api/debug/bad-frame` | 注入 `ec: "abc"` 的非法帧（验证 F10） |
| POST | `/api/debug/close-connections` | 强制断开所有 WS（验证 F08/F09） |
